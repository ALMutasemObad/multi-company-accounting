# حالة تنفيذ النظام المحاسبي متعدد الشركات

آخر تحديث: 25 أغسطس 2026

## ملخص تنفيذي

- البنية: Modular Monolith داخل npm workspaces.
- الخادم: Express وTypeScript وPrisma 7.9.1.
- الواجهة: React وVite بواجهة عربية وإنجليزية وأردية وهندية تشغيلية تشمل أرصدة المخزون وحركاته إضافة إلى الوحدات السابقة، مع RTL/LTR والتجاوب.
- قاعدة التطوير: MariaDB 10.4 عبر XAMPP.
- الترحيلات الحالية: 38؛ يضيف الترحيل 38 هوية مصدر فريدة لحركات الفواتير من دون مفتاح أجنبي عابر للسياقات، وتعيد CI تطبيق السلسلة كاملة على MariaDB 10.11 وMySQL 8.4 معزولين قبل النشر.
- حزمة التحقق: 327 تحققًا آليًا في 72 ملفًا؛ 229 اختبار API، و23 للواجهة، و26 للبنية التحتية، و48 حالة Playwright للمصفوفة المتجاوبة، ورحلة E2E كاملة.
- الحالة: نجح نشر المرحلة 58 عبر GitHub Actions رقم `32795114506` على الالتزام `7a1fbd3` بعد بوابتي MariaDB 10.11 وMySQL 8.4 والبناء والفحص البصري وE2E والنسخ/الاستعادة؛ تُعاد البوابات نفسها لمرشح المرحلة 59 قبل تفعيله.
- الحوكمة المعمارية: اعتُمدت ضوابط DDD وحدود الـBounded Contexts وADR-003؛ نُفذ `PostingEngine` وعقد عناصر الذمم والـTransactional Outbox، وحُسمت ملكية `Tax` و`Treasury` ودفتر الكميات في `Inventory`.
