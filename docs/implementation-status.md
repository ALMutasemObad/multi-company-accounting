# حالة تنفيذ النظام المحاسبي متعدد الشركات

آخر تحديث: 21 أغسطس 2026

## ملخص تنفيذي

- البنية: Modular Monolith داخل npm workspaces.
- الخادم: Express وTypeScript وPrisma 7.9.1.
- الواجهة: React وVite بواجهة عربية تشغيلية للوحة التحكم والتقارير والعملاء والسندات والسنوات والفترات والقيود اليومية ودليل الحسابات ومراكز التكلفة والخزينة وطرق الدفع ودعم كامل لـRTL والتجاوب.
- قاعدة التطوير: MariaDB 10.4 عبر XAMPP.
- الترحيلات الحالية: 22؛ تم تطبيقها من الصفر على MySQL 8.4.11، وأول 21 مطبقة على MariaDB المحلية المتوقفة حاليًا.
- الاختبارات الناجحة: 88 اختبارًا في 30 ملفًا.
- الحالة: فحص TypeScript وبناء الإنتاج وMySQL 8 والنسخ والاستعادة وحزمة التشغيل المنقاة ناجحة.

## ضوابط معمارية مطبقة

- كل المبالغ المالية `DECIMAL` وتنتقل في API كنصوص.
- كل البيانات التشغيلية مقيدة بالشركة في الاستعلامات والعلاقات المركبة.
- المستندات تستخدم `DRAFT / POSTED / CANCELLED / REVERSED`.
- التعديل للمسودة فقط؛ التصحيح بعد الترحيل يتم بالعكس.
- العمليات الحساسة تستخدم CSRF وRBAC وOptimistic Version وIdempotency.
- الفجوات في تسلسل المستندات مقبولة ومدققة لأن الرقم يحجز عند إنشاء المسودة.
- البيانات الحساسة لا تعاد بصورتها الخام في استجابات API.
