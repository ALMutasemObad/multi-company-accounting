# مرشح محلي: تتبع إخفاق إنشاء شركة المجموعة

## المنجز

بُني هذا المرشح من `origin/main` عند `381dfde` وجمع فحص أهلية عملة خطة البداية وتشخيص إخفاقات `503` الآمن واختبارات HTTP، ثم سد فجوة معرّف الطلب بين الخادم والعقد والواجهة. تلتقط الواجهة `X-Request-ID` الآمن من الاستجابة، أو `requestId` من جسم الخطأ عند غياب الترويسة، وتعرضه بجانب رسالة تعذر تحميل خيارات الشركة أو إنشائها. يُزال الرقم عند إعادة المحاولة أو نجاح الطلب أو بدء شركة أخرى. لا تُعرض للمالك أسباب الخادم الداخلية أو بيانات حساسة، ولا تتغير سياسة مفتاح التكرار.

صار عقد OpenAPI يقبل معرّفات الطلب الآمنة المسموح بها في `requestLogger`، ومنها UUID، بطول 8–128 حرفًا من الحروف الإنجليزية والأرقام والنقطة والشرطة والشرطة السفلية. الحراس المولدة محدثة، ورسائل الواجهة مترجمة في العربية والإنجليزية والأردية والهندية.

## دليل التحقق المحلي

- `109` اختبارات API مركزة ناجحة، و`10` اختبارات تكامل متجاوزة لعدم توفر MariaDB. تشمل رفض معرف غير آمن، وفحص خيارات العملة، وتسجيل `503` دون اسم الشركة أو رقم هاتفها أو جسم الطلب.
- `5` اختبارات وحدة لعميل API و`8` حالات متصفح مُحاكية لتأسيس الشركة ناجحة، بما فيها إظهار رقم التتبع وإزالته عند إعادة المحاولة.
- حزمة الواجهة العامة: `834` ناجحة و`35` متجاوزة. نجح فحص أنواع API والواجهة وبناؤهما، و`contracts:check` و`i18n:check`.
- لم تُشغّل اختبارات قاعدة حقيقية أو CI بعيد أو تحقق على البيئة التي أنتجت صورة البلاغ؛ لم يُنشأ سجل شركة حقيقي.

## حدّ النتيجة والخطوة التالية

هذا تحسين تشخيص وتجربة إخفاق، لا إثبات لسبب الخطأ المصوّر ولا إصلاح مؤكد له. يبقى البلاغ P0 مفتوحًا. يحتاج مسؤول البيئة إلى ربط محاولة جديدة أو سجل محفوظ بمعرّف طلبها بقراءة مخوّلة، وتحديد سبب الخادم الفعلي، ثم اختبار سيناريوه على قاعدة معزولة قبل تقرير إصلاحه. لا يُغيَّر كتالوج أو خطة حية ولا تُكرَّر محاولة حيّة بمفتاح جديد استنادًا إلى التخمين.

المرشح محلي وغير مدمج؛ لم يحدث push أو PR أو نشر، ولا ينقل نجاح Staging سابقًا إلى هذا التغيير.
