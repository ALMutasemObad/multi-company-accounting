# جمع محلي: إدارة المشاريع وكتالوج الخدمات

الأساس `origin/main` عند `17917803dfec5c403066773009e8f60be462d70b`. استعيدت شريحة كتالوج الخدمات المراجَعة من الفرع المحلي `task/service-catalog-offerings-sc1a-20261004`، ثم سجل المشاريع العامة من `task/general-project-register-gpm1-20261004`. لا يشير هذا الجمع إلى دمج في `main` أو نشر.

## حدود الفصل

- «إدارة المشاريع» هي سجل `GeneralProject` مستقل بصلاحيات `general_projects.*` ووحدة `GENERAL_PROJECTS`. لا يستخدم كلمة «مهنية» في اسمه أو نماذجه أو واجهته، ولا يتصل بالقضايا أو العقود المهنية أو الفوترة.
- «إدارة الخدمات المهنية» هي كتالوج تعريفات `ServiceCategory/ServiceOffering/ServiceOfferingVariant` مستقل بصلاحيات `services.*` ووحدة `SERVICE_CATALOG`. لا ينشئ مشروعًا أو فاتورة.
- حُلّت تعارضات `schema.prisma` وملف الحراس المولّد واختبار جرد OpenAPI. أبقيت نماذج وسجلات ووحدات وصلاحيات المجالين منفصلة. الترحيلان إضافيان؛ `GENERAL_PROJECTS` تُسجّل غير نشطة، و`SERVICE_CATALOG` باقية غير نشطة ولا تُمنح استحقاقًا في هذه الشريحة.

## دليل التحقق المحلي

- نجح `prisma validate` و`prisma:generate` على المخطط الموحّد باستخدام عنوان قاعدة شكلي فقط، دون اتصال بقاعدة.
- نجح `contracts:check` على 424 عملية و213 جسم طلب و2742 جسم استجابة، وفحص أنواع API وWeb وبناؤهما.
- نجحت 69 حالة API مركزة في 10 ملفات و13 حالة Web مركزة في 3 ملفات، مع `i18n:check` و`ui:check` (33 عنوان صفحة و73 منطقة جدول).
- نجحت حزمة Web الكاملة محليًا: 838 حالة ناجحة و35 متجاوزة في 73 ملفًا ناجحًا و4 ملفات متجاوزة.
- نجح فحص حدود المعمارية: 382 ملف مصدر، 1666 استيراد، صفر انتهاكات وصفر تحذيرات؛ ونجحت حالاته الاختبارية الـ51. سُجل محوّلا الحسابات والضرائب كمنافذ قراءة معلنة للكتالوج.
- شُغّلت حزمة API الكاملة بعاملين، لكنها لم تُخرج نتيجة نهائية بعد انتظار مطوّل وأوقفت يدويًا؛ لا تُعد ناجحة ولا فاشلة بناءً على هذا التشغيل. يلزم تشخيص سبب التعليق وإعادتها قبل اعتماد شامل.
- لم يُشغّل ترحيل أو اختبار تكامل على MySQL/MariaDB أو اختبار متصفح متصل؛ المنفذ المحلي `127.0.0.1:3306` غير متاح عند الفحص. نجاح البناء والعقد لا يثبت رحلة مستخدم تشغيلية أو سلامة الترحيل على بيانات فعلية.

## المتبقي قبل أي تفعيل

1. تشغيل الترحيلين على قواعد اختبار معزولة وفحص الترقية والتراجع وعزل الشركات والتزامن.
2. تجربة الواجهتين في المتصفح بعد توفير قاعدة اختبار، وفحص RTL/LTR والهاتف ولوحة المفاتيح.
3. استكمال مراحل ومهام واعتماديات إدارة المشاريع في شريحة لاحقة؛ السجل الحالي ليس نظام مشاريع مكتملًا. وكذلك دفاتر الأسعار ليست ضمن شريحة كتالوج الخدمات الحالية.
4. قرار استحقاق وتفعيل مستقل لكل وحدة، وإذن جديد قبل أي push أو PR أو دمج بعيد أو نشر.
