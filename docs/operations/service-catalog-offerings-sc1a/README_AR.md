# SC-1A — كتالوج الخدمات المستقل (عمل جارٍ)

## المنفذ محليًا

- أُضيف نموذج التصنيفات والعروض وبدائل الخدمة، مع مفاتيح شركة مركبة للروابط الاختيارية والفهرسة، دون روابط إلى مشروع أو عميل أو فاتورة أو صنف مخزون.
- ترحيل توسعي للجداول الثلاثة فقط؛ لا ينشط `SERVICE_CATALOG` ولا يمنح استحقاقًا لأي شركة. التراجع التشغيلي يحتفظ بالبيانات.
- سياسة دورة الحالة ونافذة التوفر النصف مفتوحة وقفل وحدة التسعير بعد أول تنشيط. عولجت حالة البداية المفتوحة (`availableFrom = null`) بحيث لا يعاد تفسير ماضيها بعد التنشيط.
- حجز رمز `SVC-######` من تسلسل الشركة، وتعريف صلاحيات `services.*` وعزلها عن `sales_catalog.*` وعن صلاحيات المشاريع؛ تبقى غير فعالة دون استحقاق الوحدة.
- نُفذ مسار API للتصنيفات فقط: قائمة محدودة وتفاصيل وإنشاء وتعديل وانتقال حالة؛ أوامر الكتابة مع CSRF والصلاحية ومفتاح إعادة المحاولة والنسخة والتدقيق في المعاملة. عقد OpenAPI مولّد ومطابق للمسارات.
- أُضيفت قائمة وتفاصيل وإنشاء وتعديل عروض الخدمة برمز خادمي، مع إسناد تصنيف نشط من الشركة نفسها. مسارات الإدارة تتطلب `services.manage`؛ تبقى `services.view` لاختيار الخدمة المنقح لاحقًا، لا لقراءة التصنيفات المتقاعدة أو المسودات.
- راجعت الملاحظة الأمنية المستقلة: أضيفت نسختا السجل وأسماء الحقول المتغيرة المنقحة إلى التدقيق، وقُصرت قراءات الإدارة على صلاحية الإدارة. ويقفل إسناد التصنيف صفه لئلا يتقاعد أثناء الإنشاء.
- أُضيفت بدائل الخدمة: قائمة محدودة، إنشاء وتعديل، وانتقال حالة. يقفل الأمر العرض الأب، ويثبت وقت أول تنشيط، ويمنع تغيير وحدة التسعير بعده أو إعادة كتابة توفر ماضٍ وفق تاريخ الشركة المحلي. تنشيط العرض يتطلب بديلًا غير متقاعد.

## الأدلة والحدود

- Prisma validate وPrisma Client generate: ناجحان باستخدام عنوان قاعدة شكلي للتحقق فقط، دون اتصال فعلي.
- اختبارات API المركزة (العقد المولّد، تطابق المسارات، HTTP، السياسة، المخطط، الاستحقاق): 50 ناجحة بعد API البدائل. فحص أنواع API وWeb: ناجح. `contracts:check`: ناجح.
- بدأت حزمة API الكاملة لكن اختبار جرد OpenAPI فشل أولًا بسبب عدد العمليات القديم؛ عُدّل ثم نجحت الحزمة المركزة. التشغيل الشامل لم يتقدم بعد ذلك وتوقف يدويًا؛ لا يُسجّل نجاحًا شاملًا.
- لم يشغّل الترحيل أو اختبار تكامل على MySQL/MariaDB؛ لا خدمة على المنفذ المحلي 3306 وقت الفحص.
- API التصنيفات والعروض والبدائل موجود دون مراجع الحساب/الضريبة الافتراضية ودون أداة اختيار منقحة؛ لا واجهة مستخدم موصولة، ولا اختبار متصفح، ولا CI، ولا PR، ولا نشر. هذا ليس نظام كتالوج مكتملًا.

## المتبقي ضمن الشريحة

1. إتمام مراجع حساب الإيراد وضريبة المخرجات الافتراضية عبر منافذ سياقها مع تحقق الشركة والجاهزية، وإضافة `selection-options` منقح لا يعرض مسودات الإدارة.
2. واجهة `#services` مستقلة، بحث وقوائم محدودة، وترجمة وإتاحة.
3. اختبارات تكامل على MySQL/MariaDB لقواعد العزل والتزامن والتراجع ثم فحص متصفح قبل أي قرار تفعيل.

دفاتر الأسعار والتسعير المؤرخ `SC-1B` خارج هذه الشريحة، ولا تُربط الخدمة بالمشاريع العامة.
