# مركز التقارير — الشريحة الأولى

## القرار

صفحة «مركز التقارير» هي مدخل الاكتشاف والمعاينة والتصدير. لا تصبح مالكًا لحقائق
المخزون أو دفتر الأستاذ. يحتفظ كل سياق باستعلام التقرير الدلالي الخاص به، ويستدعيه
مركز التقارير عبر منفذ قراءة محدود. قالب `document-output-kernel` مسؤول عن شكل PDF
والخطوط واتجاه الجدول وتكرار رأسه وترقيم الصفحات، لا عن حساب الرصيد أو حالة الجرد.

## محضر جرد المخزون

- تُستمد البيانات من `InventoryCountService.report()` التي تقرأ **كل** بنود جلسة
  الشركة، ولا تستخدم بحث شاشة الجرد أو ترقيم صفحتها.
- يحمي API القائمة وPDF بصلاحية `inventory_counts.manage`. تُراجع عضوية الشركة وسياقها
  بواسطة المصادقة الحالية؛ لا يقبل الطلب `companyId` من المتصفح.
- يعرض PDF اسم الشركة والجلسة والمستودع والتاريخ والحالة والقطع المستندي وأعضاء اللجنة
  والاعتماد وجميع الأصناف والفروقات وأسبابها والتوقيعات. يبقى Excel التفصيلي الحالي
  متاحًا من المركز.
- يعلن المستند صراحة عدد الأصناف غير المجرودة؛ تنزيل مسودة لا يحولها إلى محضر معتمد.
- يُسجل تصدير PDF في التدقيق بنطاق الشركة ومعرّف الجلسة وعدد الصفوف دون نسخ محتوى
  البنود إلى سجل التدقيق.

## معيار إضافة تقرير جديد

1. عقد قراءة مملوك للسياق المصدر مع عزل شركة واختبار اكتمال البيانات.
2. صلاحية API محددة وتسجيل تصدير عند حساسية المستند.
3. قالب إخراج يستخدم `document-output-kernel`، لا `window.print()` على جدول تفاعلي.
4. معاينة وتصدير في المركز مع بيان نطاق التقرير وحالته.
5. اختبار PDF بصري متعدد الصفحات، واختبار عدم إسقاط بيانات بسبب فلاتر الواجهة.

## حدود هذه الشريحة

أصبح زر «طباعة المحضر» داخل شاشة الجرد يفتح PDF الكامل نفسه في تبويب جديد بدل
طباعة جدول الشاشة الحالي. إعادة تصميم بقية التقارير القائمة والانتقال التدريجي إلى
قوالب مشتركة تقع في شرائح لاحقة؛ لم تُعتبر منجزة هنا.
