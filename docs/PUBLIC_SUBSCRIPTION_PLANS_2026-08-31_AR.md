## ما يراه الزائر

يفتح `/plans` (ويعمل `/#plans` أيضًا) دون تسجيل دخول: مقدمة دعائية، أعمدة
لمقارنة الخطط، السعر ودورة الفوترة والضريبة، الحصص والوحدات المشمولة، الإضافات
الاختيارية وأسعارها، زر اختيار لكل خطة، أسئلة شائعة، وروابط الدخول والتسجيل.
ثلاثة أعمدة على الكمبيوتر، عمودان على التابلت، وعمود واحد على الهاتف.

الكتالوج يأتي من قاعدة البيانات لا من أسعار ثابتة في React. الأسماء والأسعار
في صور الاختبار **fixtures اصطناعية** داخل `scripts/visual-qa-server.mjs` فقط،
وليست اعتمادًا تجاريًا أو Seed للإنتاج. لا تُدرج صفحة وهمية ببطاقات حقيقية الشكل
إذا لم يعلن المشغل أي خطة؛ يظهر بدلها تنبيه «خططنا العامة قيد التجهيز».

## كيف يجهّز مشغل المنصة عروضه بعد النشر

1. افتح **خطط واشتراكات المنصة** (`#platformSubscriptions`) بحساب Platform Operator.
2. اختر الخطة أو أنشئها، وحدد اسم العرض ووصف المزايا والدورة والعملة والسعر والضريبة
   والحدود والوحدات المشمولة والاختيارية. لا يُطلب اعتماد أسعار من المطور.
3. اختر سياسة الخدمة الذاتية المناسبة وتاريخ سريان حاليًا أو سابقًا، ثم انشر الإصدار.
4. في قسم **العرض في صفحة الخطط العامة** اضغط **إظهار للعامة** للإصدار المقصود.
   الإظهار يحتاج خطة نشطة مكتملة وسارية، ولا ينشر المسودات أو نسخ Legacy.
5. افتح رابط **عرض صفحة الخطط العامة** وافحص العرض كزائر. يستطيع المشغل إخفاء
   الإصدار بالزر نفسه دون إلغاء اشتراك العملاء القائم.

زر الزائر يحفظ معرف الإصدار مؤقتًا في تبويبه وينقله للتسجيل فقط. لا يُفعّل خطة
مدفوعة ولا يحصل مبلغًا، ولا يحتفظ السعر المعلن بصفته عرضًا مضمونًا بعد تغيير
الكتالوج. يؤكد المستخدم طلبه لاحقًا من صفحة اشتراك النشاط وفق صلاحياته وعقد الخادم.

## أدلة التحقق المحلية

بيئة التنفيذ: Windows، Node 24.19.0، npm 12.0.2، الاعتماديات المقفلة دون إضافة
حزمة تشغيل جديدة.

| البوابة | النتيجة |
|---|---|
| Prisma generate / validate | ناجح |
| TypeScript للمصدر واختبارات API/Web وE2E | ناجح |
| OpenAPI 1.44.0 والتوليد وRedocly 2.46.2 | ناجح: 316 عملية، 167 جسم طلب، 2092 جسم استجابة |
| API كامل دون DB خارجية | 471 ناجحًا، 136 متجاوزًا بسبب غياب DB، صفر فشل |
| Web كامل | 73 ناجحًا |
| Infra كامل | 54 ناجحًا |
| i18n / UI guards | ناجح |
| بناء API وWeb | ناجح |
| الصفحة العامة على أربعة أحجام وأربع لغات | 32 اختبارًا ناجحًا ضمن مجموعة الواجهات الكاملة: 144 ناجحًا، صفر فشل |
| MariaDB 10.11 / MySQL 8.4، empty + upgrade، E2E قاعدة حقيقية | **لم تُشغل لهذه الدفعة؛ شرط مانع للدمج** |

تشمل الاختبارات: إسقاط الحقول العامة فقط، منع ظهور الخاص والمسودة وغير الساري،
العد والصفحات الخادمية، الأرقام الدقيقة، صلاحية المشغل وCSRF والجسم الصارم ونسخة
التزامن، انتهاء تفضيل الاختيار والتخزين المعطل، الربط بالتسجيل دون دفع أو تفعيل،
حالات الكتالوج الفارغ والفشل والمهلة وإعادة المحاولة، والتنقل بلوحة المفاتيح.
أضيف اختبارا DB للتزامن والترقيم ومرشحات العرض ضمن suite الاشتراكات القائمة؛
يبقيان متجاوزين محليًا حتى تشغيل `RUN_DB_TESTS=true` على قاعدة الاختبار المدعومة.

اكتشف الاختبار الموسع سقوط الجزء الكسري في منسق العملات عند إخفاء الأصفار:
أصلح `formatCurrencyDecimal` وأثبت `123.4567` و`0.0001`، مع استمرار اختبار
القيم الكبيرة والتقريب السابق. لم تتغير قيم قاعدة البيانات أو حسابات الفوترة.

## ما لم يُغلق

- لا إثبات تحميل ممثل أو SLO جديد؛ حدود العرض والمهلة ليست قياسًا لأداء الاستضافة.
- لا اختبار تشغيل الترحيل أو الرجوع على المحركين محليًا، ولا نجاح CI لهذا الفرع.
  الموجود المحلي XAMPP/MariaDB 10.4 ليس بديلًا لبوابتي الإصدار.
- لا رفع Git أو PR أو دمج أو نشر في هذه الدفعة. يحتاج ذلك تفويضًا مستقلًا ثم
  نجاح جميع بوابات CI، ولا تُغيّر الواجهة المنشورة بمجرد إنجاز ملفات محلية.
- اعتماد المحتوى والأسعار التجارية وإظهار الإصدارات مسؤولية مشغل المنصة.
- حادثة البطء الخارجي و`Failed to fetch` السابقة ليست مغلقة بهذا التغيير؛
  المهلة الجديدة تخص الكتالوج العام فقط، لا كل مسارات المصادقة أو الاستضافة.
