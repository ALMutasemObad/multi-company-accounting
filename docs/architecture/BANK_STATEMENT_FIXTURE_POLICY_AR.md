# سياسة عينات كشوف البنك

- يمنع حفظ كشف بنك حقيقي أو اسم عميل/مورد حقيقي أو IBAN أو رقم حساب أو مرجع أو مبلغ مأخوذ من الإنتاج.
- تبنى كل Fixture اصطناعيًا، وتستخدم معرفات معلنة بوضوح للاختبار وقيمًا غير سرية.
- لا تنسخ بيانات من لقطة شاشة أو تذكرة دعم أو log. إذا احتاج خطأ إنتاجي إلى إعادة بناء، يعاد تكوين أصغر مثال صناعي يثبت البنية فقط.
- تحفظ العينات تحت `apps/api/tests/fixtures/bank-statements` وتراجع ككود. لا تسجل محتويات الملفات أو الحسابات في logs.
- عينات XML الخبيثة تبقى صغيرة ومغلقة ولا تشير إلى أسرار فعلية؛ هدفها إثبات الرفض قبل التحليل.
- أي إضافة Fixture جديدة تتطلب اختبار عقد يوضح الغرض، وصيغة/Profile صريحة، وفحصًا بشريًا لغياب البيانات الحقيقية.
