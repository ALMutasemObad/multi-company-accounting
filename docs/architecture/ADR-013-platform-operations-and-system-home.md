# ADR-013: لوحة تشغيل المنصة والصفحة الرئيسية للأنظمة

## السياق

تخدم الواجهة الحالية مدير شركة واحدة وتعرض كل الوحدات في قائمة جانبية طويلة، بينما
تحتاج الشركة المطوّرة رؤية تشغيلية مجمعة عن تبني المنصة وصحتها عبر جميع الشركات.
صلاحية `ADMINISTRATOR` الحالية خاصة بالشركة، ولذلك لا يجوز استخدامها وحدها لمنح
وصول عابر للشركات.

## القرار

- يضاف سياق قراءة فقط باسم **Platform Operations** لا يملك جداول أعمال، ويجمع
  مؤشرات غير مالية وغير شخصية عبر `PlatformAnalyticsQueryPort`.
- يفوض الوصول عبر قائمة بريد مشغّلي منصة صريحة
  `PLATFORM_OPERATOR_EMAILS` يطابقها Identity عبر Query Port صغير. لا تمنح أدوار
  الشركة هذا الوصول ولا يوجد wildcard في الإنتاج.
- يعيد `GET /platform/capabilities` قيمة منطقية فقط، ويعيد
  `GET /platform/overview` بيانات مجمعة للمشغل المصرح له.
- لا تعرض اللوحة أسماء الموظفين أو المستخدمين أو البريد أو تفاصيل المستندات أو
  المبالغ؛ يسمح باسم الشركة في ترتيب النشاط لأنه بيان تشغيلي للمالك المطوّر.
- يقاس “عدد العمليات” من `AuditLog` كأوامر أعمال مسجلة، وتعرض المستندات المالية
  كمؤشر مستقل حتى لا تخلط الدلالتين.
- تصبح `#home` الصفحة الافتراضية وتعرض الوحدات كبطاقات مجمعة. تبقى
  `#dashboard` لوحة الشركة المالية، وتظهر `#platform` فقط للمشغل المصرح له.

## البدائل المرفوضة

- استخدام دور مدير الشركة للوصول المنصّي: يفتح بيانات جميع المستأجرين لأي عميل
  يملك الدور نفسه.
- تخزين إجماليات موازية في جداول جديدة: يضيف مصدر حقيقة ومزامنة غير لازمين للشريحة
  الأولى.
- قراءة المقاييس التشغيلية الخام أو سجلات المستخدمين في المتصفح: توسع كشف البيانات
  الحساسة ولا يحتاجها القرار الإداري.
- استبدال القائمة الجانبية بالكامل: يضعف الوصول السريع؛ الصفحة الرئيسية مكملة لها.

## النتائج

لا يلزم DDL أو Migration أو Dependency جديدة. الرجوع يعيد نسخة التطبيق السابقة فقط.
يبقى مسار الإنتاج مغلقًا ما لم تضبط قائمة مشغّلين صريحة، بينما يسمح التطوير المحلي
للحساب `admin@mcap.local` لتسهيل التحقق فقط.

## نتيجة التنفيذ المحلي

نُفذ السياق بمنافذ قراءة فقط ومساري OpenAPI، وأصبحت `#home` الصفحة الافتراضية
مع بقاء لوحة الشركة المالية في `#dashboard`. اجتازت الخدمة اختبارات التفويض
والتجميع والعزل المعماري، واجتازت الواجهة البناء والترجمات الأربع وفحصي سطح المكتب
والهاتف. لم يضف التنفيذ جدولًا أو Migration أو Dependency، ولم يحدث نشر أو Push.
