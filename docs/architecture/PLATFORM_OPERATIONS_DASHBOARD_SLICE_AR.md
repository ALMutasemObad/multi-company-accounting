# شريحة لوحة تشغيل المنصة ودليل الأنظمة

## النطاق

1. صفحة رئيسية افتراضية تقسم الوحدات إلى التشغيل التجاري، الخدمات والقوى العاملة،
   المالية والرقابة، والإدارة.
2. بطاقات بأيقونات ووصف وإجراء فتح مباشر مع استجابة لأربع لغات وRTL/LTR.
3. لوحة مطوّر بفترات 7 و30 و90 يومًا.
4. مؤشرات الشركات والموظفين والحسابات والجلسات والعمليات والمستندات والتنبيهات
   وOutbox وتغطية ربط الموظفين وتبني الشركات.
5. اتجاه ستة أشهر، نشاط الوحدات، وأكثر خمس شركات نشاطًا دون تفاصيل مستخدمين.

## الأمان والخصوصية

- `/platform/capabilities` متاح للجلسة المصادق عليها ويكشف boolean فقط.
- `/platform/overview` يحتاج مستخدمًا مطابقًا لقائمة
  `PLATFORM_OPERATOR_EMAILS`؛ لا تكفي صلاحية أو دور داخل شركة.
- لا بريد ولا أسماء أفراد ولا IP ولا User-Agent ولا وصف مستند أو مبلغ مالي في
  الاستجابة.
- الاستجابة `no-store` وتخضع لمحدد المعدل والـdeadline ومدقق OpenAPI المركزي.

## نموذج القراءة والملكية

- لا نموذج بيانات جديد.
- `PlatformOperationsService` ينسق التفويض والنافذة الزمنية فقط.
- Identity يملك `PlatformIdentityQueryPort` لقراءة بريد المستخدم داخليًا.
- `PrismaPlatformAnalyticsQueryAdapter` Query Layer للقراءة المجمعة فقط؛ لا توجد
  عمليات create/update/delete ولا معاملة كتابة.

## العقد والعكس

- `GET /platform/capabilities`.
- `GET /platform/overview?days=7|30|90`.
- العكس تشغيلي بإرجاع نسخة التطبيق؛ لا بيانات أو مخطط يلزمان تنظيفًا.
- تعطيل اللوحة دون rollback يتم بإفراغ `PLATFORM_OPERATOR_EMAILS` في الإنتاج.

## بوابة الإغلاق

- OpenAPI والحراس والمسارات متطابقة.
- رفض مستخدم الشركة غير المدرج، والسماح للمشغل فقط.
- اختبارات التجميع وعدم كشف بيانات شخصية وعرض اللغات والمقاسات.
- TypeScript وAPI/Web وbuild وi18n/UI وE2E ناجحة.
- لا Dependency ولا نشر ولا Push.

## نتيجة الإغلاق المحلي

- نجح TypeScript للـAPI والواجهة، والبناء الإنتاجي، وRedocly، وتطابق الحراس والعقد.
- نجحت اختبارات خدمة التفويض والتجميع الفعلي على MariaDB والحارس المعماري وتكافؤ
  المسارات، كما نجحت اختبارات الواجهة وE2E لحالتي المشغل والمستخدم العادي.
- أضيفت الصفحتان إلى مصفوفة Chromium للغات الأربع عند عروض
  390/768/1440/1920، مع تحقق مستقل من عدم وجود تمدد أفقي على الهاتف.
- تحقق المسار الحقيقي محليًا بحساب التطوير: 9 مجموعات نشاط وست نقاط اتجاه زمني،
  مع بقاء استجابة اللوحة مجمعة وخالية من بيانات الأفراد والتفاصيل المالية.
