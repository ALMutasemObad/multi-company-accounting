# سياسة تخزين صور المنتجات

صور المنتجات اختيارية ضمن كتالوج المخزون. لا تُعرّف هوية الصنف ولا تغيّر الباركود أو ملف البيع أو تقييم المخزون أو القيود المالية.

## التخزين والعزل

- تخزن قاعدة البيانات البيانات الوصفية فقط: الشركة والصنف والبصمة ونوع الوسائط والأبعاد والأحجام وإصدار المقارنة المتفائلة. لا تخزن bytes أو مسارات ملفات.
- `MEDIA_ROOT` مسار مطلق ودائم خارج مجلدات الإصدارات وواجهة الويب. يفشل تشغيل الإنتاج إن لم يُضبط. يجب نسخ هذا المجلد مع قاعدة البيانات واستعادتهما إلى نقطة استرداد متوافقة.
- يولد الخادم كل المسارات من معرفات رقمية متحققة للشركة والصنف ومن SHA-256 لحزمة مشتقات محددة الإصدار ومفصولة الأطوال (الأصل الطبيعي + thumbnail المخزون + thumbnail POS). لا يقبل أسماء أو مسارات من العميل، ويرفض traversal والروابط الرمزية.
- تستخدم الملفات مجلدات immutable موجهة بالمحتوى، وكتابة مرحلية على القسم نفسه ثم rename ذري، وصلاحيات `0750` للمجلدات و`0640` للملفات. تُزامن الملفات والمجلدات (`fsync`) قبل اعتماد metadata على POSIX؛ على Windows يبقى rename ذريًا على القسم نفسه مع no-op موثق لمقابض المجلد غير المدعومة. لا يُحذف إصدار قديم داخل مسار الطلب أو الحذف المنطقي كي يبقى ترتيب DB snapshot ثم media archive قابلًا للاستعادة حتى مع الرفع المتزامن.
- هذا الإصدار **append-only ولا يحتوي أداة GC حاذفة**. يجب مراقبة حجم `MEDIA_ROOT` دوريًا (`du`) والتنبيه قبل نفاد المساحة. تنظيف الأيتام مؤجل صراحة، ولا يجوز تفعيله قبل توفير أمر صيانة مستقل يشارك قفل `.pipeline.lock` مع النسخ الاحتياطي، ينتظر فترة سماح، ويعيد فحص مراجع DB تحت قفل صف الصنف قبل كل حذف. هذا قيد تشغيلي مقصود وليس ادعاءً بوجود reconciler حالي.

## المعالجة والتقديم

- يقبل الرفع raw JPEG/PNG/WebP فقط مع حدود للحجم والبكسلات، وتطابق MIME مع التنسيق الفعلي، ومنع الحركة وأكثر من أربع قنوات.
- يعيد Sharp الاتجاه والترميز إلى WebP طبيعي منزوع metadata، وينتج thumbnail بحجم 256 للمخزون و512 لنقاط البيع. لا تعرض الواجهات الأصل الطبيعي.
- للمخزون ونقاط البيع مسارا قراءة وصلاحيتان منفصلتان. الروابط لا تكشف إلا معرف الصنف وإصدار الصورة، وتستخدم `ETag` و`private, max-age=31536000, immutable`.
- يتطلب PUT وDELETE حماية CSRF وشرطًا متفائلًا: `If-None-Match: *` للصورة الأولى، أو `If-Match: "product-image-vN"` للاستبدال والحذف.

## التشغيل

قبل التفعيل، يُنشأ `MEDIA_ROOT` بصلاحيات مستخدم التشغيل ويُتحقق أنه خارج release/web root، وأن مضيف cPanel يطابق متطلبات Sharp وNode. لا تكتمل جاهزية الإنتاج حتى ينجح تمرين النسخ والاستعادة لقاعدة البيانات والوسائط معًا. الرجوع البرمجي آمن لأن الملفات immutable؛ أما rollback للمخطط فيتطلب قرارًا صريحًا لحفظ مجلد الوسائط أو تقاعده.
