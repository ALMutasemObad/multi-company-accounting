# حالات الفراغ الواعية بالصلاحيات

## النطاق

- الأساس: `731fc11f3635143558fcd6431b864afd0807ff53`.
- الصفحات: الموردون، سندات القبض، وسندات الصرف فقط.
- لم تُعدّل ملفات الترجمة أو سياسات الصلاحيات المشتركة أو واجهات API.

## ما نُفذ

- أصبح وصف حالة القائمة الفارغة محايدًا لمستخدم العرض فقط، باستخدام النص القائم `referencePicker.empty`.
- بقي الوصف الإنشائي القائم كما هو عند توفر الصلاحية الدقيقة:
  - `suppliers.manage` للموردين.
  - `receipts.create` لسندات القبض.
  - `payments.create` لسندات الصرف.
- بقي بحث الموردين بلا تغيير: نتيجة البحث الفارغة تستمر في استخدام رسالة عدم وجود نتائج البحث.
- بقيت أزرار الإنشاء محروسة بسياسات `Can` القائمة، ولم يُضف مسار كتابة جديد.

## دليل التحقق

- `npm run typecheck -w @mcap/web`: ناجح.
- `npm run e2e:typecheck`: ناجح.
- Playwright على `mobile-390` و`desktop-1440`: **4/4 ناجحة**.
  - تم التحقق من غياب النص الإنشائي وأزرار الإنشاء لمستخدم العرض فقط في الصفحات الثلاث.
  - تم التحقق من ظهور الوصف والأزرار القائمة عند منح صلاحية الإدارة/الإنشاء الدقيقة لكل صفحة.
  - رصد الاختبار طلبات الشبكة وأثبت **صفر طلبات كتابة** في سيناريوهات العرض وفي كامل الاختبار.
- `npm run build -w @mcap/web`: ناجح.
- `node scripts/check-web-ui.mjs`: ناجح (`31` ترويسة صفحة و`68` منطقة جدول).
- `git diff --check`: ناجح؛ ظهرت تحذيرات تحويل نهايات الأسطر LF/CRLF فقط دون أخطاء مسافات.

## بيئة التشغيل

- كانت المساحة الحرة قبل تثبيت الاعتمادات نحو `21.73 GB` على C و`26.42 GB` على E.
- ثُبتت الاعتمادات من ملف القفل داخل worktree، مع مخزن تنزيل npm المعتمد `E:/DevelopmentCaches/npm`.
- استُخدمت منافذ الفحص القياسية `3000` و`4173` بعد التأكد من خلوهما؛ لم تُنشأ إعدادات مؤقتة.

## ما لم يُنفذ

- لا تغييرات على API أو OpenAPI أو قاعدة البيانات.
- لا تغييرات ترجمة أو سياسات صلاحيات مشتركة.
- لا دفع بعيد أو طلب دمج أو نشر.
