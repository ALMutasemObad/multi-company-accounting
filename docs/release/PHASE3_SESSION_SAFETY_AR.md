# تسليم اعتمادية الجلسة — المرحلة الثالثة

المهمة: `session-safety`، الفرع `task/session-safety`، الأساس المتحقق منه `9be397c7a435720c921425b6cb7b64e5dbab7ebc`. التنفيذ محلي داخل worktree المسجل حصراً. الالتزام النهائي يسجله أمر MarkReady في سجل مساحة العمل بعد حفظ هذا الملف.

## ما نُفذ

- تصنيف انتهاء المصادقة من HTTP 401 للمسارات المحمية؛ استثناء login/logout/csrf/password recovery. لا يصنف `INVALID_CSRF` في code أو reason كجلسة منتهية، حتى مع 401.
- جيل طلبات داخل الصفحة يلغي الانتظار ونتائج النقل القديمة عند الدخول والخروج وتبديل الشركة وانتهاء الجلسة وإزالة App. يشمل JSON والتنزيلات واستهلاك أجسام الردود. لا إعادة إرسال تلقائية.
- إشعار واحد عند تزامن ردود 401 للجيل نفسه. تفريغ صلاحيات المستخدم والشركات والتنبيهات وحالة التنقل وإظهار تسجيل الدخول برسالة مترجمة باللغات الأربع.
- حماية كتابة رمز CSRF من bootstrap قديم، وعدم مشاركة bootstrap ملغى، وعدم مسح رمز جلسة جديدة عندما ينتهي logout قديم.
- إزالة صفحات الشركة عند فتح اختيار الشركة، مع بقاء مفتاح المستخدم/الشركة الموجود على Suspense. منع التنبيهات القديمة من الظهور في السياق الجديد. لم يتغير توقيع api أو ملفات العقود.
- تمت قراءة المسودة المحفوظة في مصدر backlog قراءة فقط؛ رُفض تصنيف CSRF فيها ولم تُستورد المسودة.

## سياسة المدخلات والمسودات

تبقى مدخلات النموذج في الذاكرة عند خطأ عادي أو CSRF. عند انتهاء المصادقة الحقيقي، أو مغادرة سياق الشركة/المستخدم، تزال الصفحة وحالة النموذج. **المدخلات غير المحفوظة تضيع ولا تُستعاد تلقائيًا**؛ هذه سياسة حماية وحدّ وظيفي، وليست ميزة حفظ مسودات. تظهر رسالة واضحة عند إعادة الدخول. أكد مدير التنسيق أولوية منع التسرب وطلب مراجعة هذا القيد قبل قبول الإصدار.

لم نضف تخزينًا دائمًا للمدخلات أو كلمات المرور، ولم نمسح تخزين مسودات أو سجلات استعادة موجودة في صفحات خارج النطاق. تبقى آليات استعادة POS وغيرها مستقلة وتحتاج مراجعتها الخاصة؛ لا يدعي هذا التسليم تغطية كل نماذج النظام أو مخازنه الدائمة.

## ما لم يُختبر والمتبقي ومخاطر الدمج

- لا اختبار قاعدة بيانات أو ملفات cookies حقيقية أو إبطال جلسات خادمية؛ APIs في اختبار المتصفح محاكاة. لا تعديل بيانات بالموقع الحي.
- الإلغاء يوقف انتظار العميل ولا يثبت rollback لطلب وصل إلى الخادم. لا تغطي الحماية تغيير السياق من تبويب آخر، أو ترتيب commit لعمليات auth/context/logout في الخادم؛ ذلك يحتاج عقدًا خادميًا مستقلًا إن أُريد ضمانه.
- لم تختبر كل صفحات النظام أو كل المسودات الدائمة. اختبار المدخلات الفعلي يستخدم صفحة CRM الحالية على main؛ يعاد بعد دمج تغييرات مهمة CRM.
- فحص التنزيل والإلغاء بعد unmount محكوم بإشارات الإلغاء في اختبارات النقل؛ لم يُختبر حفظ ملف فعلي أو تنزيل عبر جلسة إنتاج.
- رسالة فقد المدخلات وقبول سياسة discard يحتاجان مراجعة الإصدار من المدير. لا تغيير مجال أو ترحيل أو اعتماد أو سجل إصدار يدوي.
- لا push أو PR أو CI بعيد أو دمج أو نشر. نجاح البناء محلي فقط.
