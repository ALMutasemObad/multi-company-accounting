## قرارات التكامل

- بقي اكتشاف إعدادات ملف الشركة متاحًا لصاحب `companies.profile.view` أو `companies.compliance.view`، مع حجب أقسام إعدادات الشركة والعملات غير المصرح بها.
- بقي اكتشاف الموارد البشرية بمنطق `anyOf` كي لا يحتاج المستخدم كل صلاحيات HR لمشاهدة مساحة العمل.
- لم تنفذ مخططات أو APIs للمشاريع العامة أو دليل الخدمات أو مركز الحسابات في هذه الدفعة؛ الوثائق تحدد الشرائح التالية وحدود الملكية فقط.
- لا تخزن أرقام الوثائق الحساسة كاملة. أي رقم وثيقة يرسله العميل يسقط حالة التحقق، بينما يحفظ إغفال الحقل الحالة السابقة.

## بوابة الإصدار

تسجل نتائج التكامل المحلي وPR وCI ودمج `main` ونشر Staging كلًا على حدة. لا يعد نجاح الاختبارات المحلية نشرًا، ولا تعد بيئة iFastNet الحالية Production حيًا. يجب أن يثبت CI الترحيلات على MariaDB 10.11 وMySQL 8.4 قبل الدمج، ثم ينفذ `deploy-staging` النسخة المشفرة والترحيل والـSeed والتبديل الذري وفحص الصحة.
