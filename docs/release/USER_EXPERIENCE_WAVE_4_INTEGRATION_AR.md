## توحيد مصدر تاريخ الشركة

أصبح `invoiceDateToday(timeZone, now)` يحافظ على واجهته العامة واختباراته،
لكنه يفوض التنسيق إلى `companyCalendarDate(timeZone, now)`. لم يعد في
`invoice-date-defaults.ts` منطق `Intl.DateTimeFormat` مكرر. يبقى fallback إلى
تاريخ UTC حتميًا عند غياب المنطقة الزمنية أو عدم صلاحيتها، بينما تستخدم
صفحات العكس الأربع المصدر المركزي نفسه.

غيّر مرشح الموجة الثالثة تبويبات التقارير إلى دلالات ARIA صحيحة. لذلك حُدّث
اختبار التدقيق المالي ليتعامل مع `role=tab` بدل `role=button` قبل تفعيل دليل
الإغلاق؛ لم يُضعف أي assertion ولم يُضف `skip` أو `fixme`.

readiness لخادم API يتطلب قاعدة غير مشغلة؛ شُغلت الرحلة نفسها عبر خادم Vite
المحلي مع اعتراضات API الخاصة بالاختبار، ثم حُذف غلاف التشغيل المؤقت.
