# مرشح إصدار تجربة المستخدم

التاريخ: 2026-09-08

الأساس: `origin/main` عند `731fc11f3635143558fcd6431b864afd0807ff53`

## النتيجة

جُمعت موجة تجربة المستخدم الخامسة مع مهام الإغلاق الثلاث: افتراض الفترة
المفتوحة وتاريخ الشركة للقيد اليدوي، وتسميات مرشحات سجل التدقيق المقروءة،
ودلالات لوحة المفاتيح والوصول لتبويبات المبيعات والمشتريات. حُل تعارضا الدمج
في `AuditLogsPage` و`ManualJournalsPage` مع إبقاء حواجز الصلاحيات من الموجة
السابقة وعدم تغيير أجسام الطلبات.

وُحّد تحويل المنطقة الزمنية إلى تاريخ الشركة عبر `companyCalendarDate` بدل
الإبقاء على نسخة ثانية في القيد اليدوي. كما فُعّلت اختبارات الفجوات العملية
القديمة للقيد اليدوي، وأكواد التدقيق، وتبويبات المستندات بعد نجاح الإصلاحات.

كشف اختبار API الكامل انجراف اختبار قديم: أصبح عقد اللغة يقبل أي وسم BCP 47
صحيح لدعم إضافة لغات مستقبلية، بينما بقي الاختبار يرفض `fr`. عُدّل الاختبار
ليقبل الوسم الصحيح ويرفض `not_a_locale`، دون تغيير عقد الإنتاج.

لم تُنفذ إضافة أو تطوير لمصروفات الموظفين في هذا المرشح؛ ظهور ملف صفحتها في
البناء مجرد قياس لحزمة الوحدة الموجودة سابقًا.

## حدود الدليل ومسار النشر

الرحلات المرئية تستخدم بيانات تركيبية واعتراضات API محلية. اختبارات قاعدة
البيانات المشروطة لم تُحسب نجاحًا محليًا؛ يجب أن تنفذها CI على MariaDB 10.11
وMySQL 8.4 قبل السماح بالنشر. الهدف الحالي في `ci.yml` ووفق دليل التشغيل هو
Staging على iFastNet، وليس Production حيًا مستقلًا. يتطلب النشر التزام دمج
واحدًا صادرًا من Pull Request إلى `main`، ثم نجاح جميع البوابات قبل التبديل
الذري وفحص الصحة.

لم يحدث push أو PR أو نشر وقت إنشاء هذا التقرير.
