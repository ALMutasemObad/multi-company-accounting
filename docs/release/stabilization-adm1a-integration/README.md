# مرشح دمج الاستقرار وADM-1A

## النطاق المدموج

- جُمعت سلسلة الاستقرار كاملة من خط الأساس `c12b6a8` حتى `33ebfe1`، بما فيها
  حراس الحدود والدين، إصلاح التسجيل، onboarding، بوابة نشر Prisma، وتقوية CSRF.
- جُمعت سلسلة `Account.version` وCAS كاملة حتى `6bdfdc4`.
- أُعيد توليد حارس OpenAPI من العقد المدموج؛ لم يُدمج الملف المولّد يدويًا.

## ديون أُزيلت أثناء التحقق

- أُصلح خطأ أقواس في اختبار onboarding كان يمنع تحليل حزمة الويب.
- استُبدل تثبيت العدد الإجمالي للهجرات في اختبارين بتحقق دلالي من وجود الهجرة
  المقصودة، حتى لا ينكسر الاختبار مع كل هجرة صحيحة جديدة.

## التحقق المحلي

- `contracts:check`: ناجح، 187 request bodies و2423 response bodies.
- حارس الحدود: 336 ملفًا، 1470 import، دون مخالفات أو تحذيرات مراجعة.
- حارس الدين: baseline ثابت، وإزالة الدين ما زالت مرتبطة بـADM-5C.
- اختبارات الحراس والبنية والنشر: 88/88 ناجحة.
- اختبارات API/CSRF/CAS والهجرات المركزة: 58/58 ناجحة.
- اختبارات الويب: 822 ناجحة، و34 متجاوزة وفق إعداداتها.
- Prisma schema validation: ناجح.
- typecheck وbuild للـAPI والويب: ناجحان.

## ما لم يُتحقق

- لم تُشغّل اختبارات MariaDB/MySQL التكاملية لعدم توفر `DATABASE_URL` لقاعدة
  اختبار فعلية. محاولة الحزمة العامة التي تشمل اختبارات قاعدة البيانات أُوقفت
  بعد انتظار الاتصال، ولا تُحسب نجاحًا.
- لم يحدث push أو PR أو CI بعيد أو نشر.
