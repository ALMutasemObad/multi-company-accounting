## التنفيذ

رسالة عامة صادقة بعد التسجيل مع دخول واستعادة الحساب الحالي. API ونموذج إنشاء
شركة جديدة للمجموعة، قصر على OWNER نشط، تأسيس مدير للشركة الجديدة فقط، منافذ المالكين
والاشتراك الخادمي القائم، تدقيق ذري وسجل تكرار دائم مستقل للمجموعة. التفاصيل في
`docs/architecture/GROUP_COMPANY_ONBOARDING_AR.md`.

قاعدة upgrade الجزئية الأولى محفوظة. لم تُحذف بيانات أو أدلة. أُغلق المحركان بعد
التحقق النهائي. سجلا التكامل النهائيان `mysql-final-tests.log` و`mariadb-final-tests.log`.
