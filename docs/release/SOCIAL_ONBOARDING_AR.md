# تسليم استكمال التسجيل الاجتماعي

## المنفذ

طُبقت سلسلة المرشح حتى `5ac8348` مرة واحدة، ثم أضيفت رحلة كاملة وآمنة للمستخدم
الجديد من Google أو Apple. تعرض الرحلة نموذج المجموعة والشركة والإعدادات والموافقة،
وتنشئ حسابًا اجتماعيًا فقط وعضوية `OWNER` وشركة واحدة ودليلًا واشتراكًا وجلسة
مصادقًا عليها في معاملة واحدة. لا يحدث دمج بالبريد، ولا تنتقل مطالبات المزود أو
رموزه إلى URL أو JavaScript.

أضيف ترحيل 73 وجدول الاستمرار، وثلاث عمليات OpenAPI، وcookies `HttpOnly` قصيرة
العمر، وCSRF ومحددات المعدل وربط المتصفح والتنظيف. أضيفت ترجمة عربية وإنجليزية
وأردية وهندية، مع أحجام خط متسقة دون خط زخرفي تحت العنوان.

## قرار الحساب الاجتماعي

الحساب الجديد لا يملك كلمة مرور محلية؛ تكون `password_hash=NULL` فقط مع إنشاء
`ExternalIdentity` ذريًا. الدخول بكلمة المرور يظل غير قابل للتمييز ويستخدم hash
وهميًا مكلفًا، وطلب إعادة الضبط يعيد القبول العام دون رسالة أو token لهذا النوع.
اعتمدت علامة البريد الموثق داخل OIDC كتحقق الاتصال لهذه الرحلة فقط، مع منع استخدامها
للربط أو مطابقة حساب قائم. تفاصيل القرار والرجوع في
`docs/architecture/SOCIAL_ONBOARDING_CONTINUATION_AR.md`.

## تحقق قاعدة البيانات

شُغل كل محرك منفردًا على datadir جديد محفوظ على E، ثم أوقف إيقافًا طبيعيًا:

- MariaDB 10.11.11 على `E:/TestDatabases/social-onboarding-mariadb1011-20260906`:
  نجح fresh لجميع الترحيلات الـ73 والـseed، ونجحت اختبارات DB المستهدفة `12/12`.
  نجح بناء قاعدة مأهولة ثم rollback إلى مخطط 72 (`الجدول=0` و`password_hash=NO`)
  وإعادة تطبيق 72→73 (`الجدول=1` و`password_hash=YES`). ثبت كذلك أن rollback
  مع حسابين اجتماعيين يفشل أولًا ويبقي الجدول والقيم دون حذف.
- MySQL 8.4.11 على `E:/TestDatabases/social-onboarding-mysql84-20260906`: نجحت
  النتائج نفسها: fresh 73 + seed، واختبارات DB `12/12`، وrollback ثم reapply
  للترقية 72→73، وفشل مغلق مع حسابين اجتماعيين دون إسقاط جدول الاستمرار.

تغطي اختبارات DB الإنشاء الذري، و`issuer + subject`، وعضوية المالك، والدليل
والاشتراك، وسباق استهلاك طلبين، وإعادة الاستخدام، وتبديل المتصفح، وتعارض البريد،
وApple private relay، وتدوير الجلسة، وعدم إنشاء outbox لإعادة ضبط حساب اجتماعي.

## بقية التحقق

- API كامل: `133` ملفًا ناجحًا و`1257` اختبارًا ناجحًا؛ التخطي `43` ملفًا و`178`
  اختبارًا هو بوابات DB/بيئات اختيارية، وقد شُغلت ملفات DB ذات الصلة صراحة على
  المحركين أعلاه.
- Web كامل: `53` ملفًا ناجحًا و`710` اختبارات ناجحة؛ `3` ملفات و`11` اختبارًا
  اختيارية متخطاة.
- اختبار المتصفح الفعلي لشاشة الحساب: `2/2`، ويشمل عرض هاتف 390px وعدم الفيضان
  وخلو DOM والطلب من البريد وكلمة المرور وissuer/subject/tokens.
- TypeScript لـAPI ومجموعة اختباراته وWeb ناجح، وبناء API وVite ناجح. بقي تحذير
  Vite القائم مسبقًا عن chunk أكبر من 500kB.
- عقد OpenAPI المولد حديث: `184` request bodies و`2359` response bodies، وفحص
  التكافؤ والمسارات ناجح.
- فحص الترجمة وفحص عقد الواجهة و`git diff --check` وفحص تسرب الأسرار ناجحة.
