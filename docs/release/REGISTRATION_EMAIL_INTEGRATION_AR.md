# تسليم تكامل بريد التسجيل

## النتيجة

دُمج تسليم بريد التسجيل فوق مرشح تكامل الحساب والشركة محليًا، دون إدخال تسجيل الدخول
الاجتماعي ودون تغيير OpenAPI أو Prisma schema أو ملفات القفل. حافظت صفحة التسجيل على
الدخول واستعادة كلمة المرور للحساب الموجود، وأضافت نتيجة عامة لا تكشف وجود الحساب،
وتوضح أن قبول طلب التسجيل أو إعادة الإرسال لا يثبت إرسال البريد أو وصوله.

يعيد مسارا بدء التسجيل وإعادة الإرسال دائمًا الجسم العام
`PENDING_VERIFICATION`. لا يعيدان `deliveryStatus` أو `lastErrorCode`. يبقى إرسال البريد
أثرًا لاحقًا للـcommit عبر Transactional Outbox، باستخدام محوّل اختباري داخل العملية في
اختبارات التكامل؛ لم تُقرأ أسرار ولم يُرسل بريد حي.

مجلدات بيانات مهمة أخرى. أُغلق كل محرك طبيعيًا قبل الانتقال إلى الآخر، وتأكد غياب
العملية والـlistener بعد الإغلاق.

- MariaDB على `127.0.0.1:3396`: نجح تطبيق 71 migration من قاعدة فارغة، ثم نجحت
  الحالات نفسها 18/18.

غطت اختبارات التسجيل الفعلية: كتابة RegistrationRequest وOutbox ذريًا قبل البريد،
الاستجابة العامة للبريد الجديد، عدم إنشاء request/outbox للهوية الموجودة، rollback عند
فشل append للـOutbox، retry بعد فشل المحوّل مع backoff والرمز نفسه، إعادة الإرسال بجيل
ورمز جديدين، منع عاملين من المطالبة بالحدث نفسه، تجاهل إعادة التسليم بعد النجاح،
dead-letter للحدث غير المدعوم، ثم التحقق المتزامن وإنشاء المستخدم والمجموعة والشركة
والاشتراك والحسابات مرة واحدة. غطت مجموعة onboarding التطبيق الفعلي للجلسة وCSRF
والصلاحيات والعزل والتكرار وإنشاء شركة إضافية للحساب الموجود.

لم تُنفذ ترقية مخطط منفصلة لأن شريحة بريد التسجيل لا تغير schema أو migration؛ البوابة
اللازمة هنا كانت fresh database على المحركين. الترحيل 71 الخاص بتكامل إنشاء الشركات
اختُبر مسبقًا بترقية 70→71 في تسليم التكامل الأساس، ولم يُعد ادعاء ذلك كدليل منفذ في هذه
الجولة.

## حدود الإثبات

قيمة `deliveryStatus=SENT` تعني أن `RegistrationMailer` قبل الرسالة وأعاد نجاحًا، ثم
حُفظت الحالة؛ لا تعني وصول البريد إلى inbox ولا فتحه ولا قراءة الرابط. لم تُستخدم Resend
الحية أو SMTP أو بيانات مستخدمين حقيقية، ولم يجر push أو PR أو CI بعيد أو نشر. لم تُشغّل
اختبارات كل قواعد البيانات العامة؛ شُغلت مجموعتا التكامل المطلوبتان فقط على المحركين.
