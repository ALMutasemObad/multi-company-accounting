# RDO-1: نواة مخرجات التقارير والوثائق

## ما نُفذ

- أضيفت نواة محايدة لمخرجات الجداول، منفصلة عن Prisma والخدمات ونماذج المجال.
- توحّد مسار CSV وXLSX في `document-output-kernel` مع طبقة توافق للمستوردين السابقين.
- انتقل PDF التقارير المالية إلى ملف تعريف مشترك للخطوط، النص RTL/LTR، المبالغ العشرية، وتخطيط metadata/header/body قبل الرسم، مع تكرار رأس الجدول على كل صفحة.
- يرفض منسق العرض العشري التقريب الضمني أو التحويل إلى `Number`، ويحمي CSV من حقن الصيغ بما في ذلك البادئات ذات المسافات.

## حدود RDO-1

- لا تغيير في `printing` أو العرض الضريبي أو Prisma أو OpenAPI أو الحزم.
- لا يتناول هذا التسليم وثائق الامتثال/الضرائب المؤجلة؛ تبقى ضمن حزم العمل اللاحقة وفق ADR-028.

## التحقق

- اختبارات وحدة للنموذج العشري، Bidi الحرفي، تخطيط الصفحات، CSV/XLSX، وثبات واجهة المصدرين، مع fixture يرسم PDF متعدد الصفحات فعليًا.
- فحص ساكن للحدود: لا استيراد لنماذج المجال أو Prisma داخل النواة، ولا `Number` في مسار تنسيق مبالغ التقرير.
