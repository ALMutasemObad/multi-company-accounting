# حزمة تنظيم مساحة العمل — تصحيح محلي

تحفظ هذه الحزمة نسخة مراجعة من أدوات الإدارة المثبتة في المجلد المحلي الأب للمستودع،
وتعليماته ودليل CI. مصدر حالة العمل المحلية هو `WORKSPACE.json` هناك، وليس نسخة جديدة داخل هذه الحزمة.
لا تتضمن الحزمة سجل المسارات الشخصية أو أرشيف الأكواد أو ملفات البيئة أو Git bundle.

## استخدام الحزمة

- الأدوات في `tools/workspace` مصممة للتثبيت في **مجلد الإدارة الأب** الذي يحتوي `project` و`WORKSPACE.json`، وليس للتشغيل مباشرة من داخل هذا المجلد في المستودع.
- `Workspace.ps1`: فحص النسخة والمهام، بدء مهمة من main بعد fetch، تسجيل نتيجة جاهزة للمراجعة، وأرشفة المهمة مع الحفاظ على تغييراتها.
- `Enter-Workspace.ps1`: إتاحة Git في الجلسة الحالية من المسار المسجل، دون تعديل PATH العام.
- `Render-Status.ps1`: توليد التقرير من السجل الوحيد.
- `Test-Workspace.ps1`: اختبارات إدارة العمل في مستودع تجريبي محلي، دون اتصال بخدمة خارجية. يحفظ أدلة الاختبار تحت الأرشيف.
- `Contain-Workspace.ps1` و`Separate-Documents.ps1` و`Archive-Legacy.ps1` و`Initialize-Registry.ps1`: أدوات عملية الاحتواء المؤرخة لهذا الجهاز؛ **ليست أدوات تهيئة عامة**. لا تُعد تشغيل عمليات النقل أو التهيئة على جهاز آخر أو سجل قائم.

راجع `START_HERE_AR.md` للقواعد والتشغيل، و`RESULT_AR.md` لنتيجة التنظيم والقيود.
لا تثبّت الحزمة فوق ملفات محلية معدلة؛ قارن البصمات والفروق وراجع تغييرات الإدارة أولًا.
يُحفظ التصحيح على فرع مستقل؛ لا يتضمن تشغيل التطبيق ولا تعديل مخططه ولا نشره.
